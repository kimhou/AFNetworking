# 01 · 设计理念与愿景

## 1.1 产品定位

**王者万象棋** 是一款**回合制策略棋类游戏**，用「棋」的形式表达「MOBA」的策略内核。

- 品类：策略 / 棋牌 / 策略对抗（SLG × Board Game × MOBA-lite）
- 形态：先做**单机 + 本地双人（Hot-seat）**，再做**异步对战**，最后做**实时联网 + 天梯赛事**
- 平台：Web（原型）→ 移动端（正式）→ 桌面 / 小程序
- 一局时长：**5–15 分钟**（可通过回合上限与棋盘规模调节）

## 1.2 命名释义

| 字 | 含义 |
| --- | --- |
| **王者** | 借鉴 MOBA（王者荣耀式）的英雄对抗、推塔取胜内核 |
| **万象** | 万象更新、包罗万象——英雄百变、地形多样、局势千变万化 |
| **棋** | 完全信息、回合制、深度策略的棋类骨架 |

## 1.3 目标人群

1. **象棋 / 国际象棋 / 围棋玩家**：想要更现代、更有成长感的策略棋。
2. **MOBA 玩家**：想在通勤、睡前、无网环境下，异步、慢节奏地享受 MOBA 策略。
3. **策略桌游爱好者**：喜欢《战棋》《火焰纹章》《陷阵之志（Into the Breach）》式的格子战棋。
4. **内容 / 赛事人群**：完全信息 + 回合制天然利于**直播解说、录像复盘、AI 教学**。

## 1.4 体验支柱（Design Pillars）

> 所有玩法决策都应服务于这三根支柱，冲突时以支柱优先级为准。

### 支柱一：一步一世界（深度策略）
- **完全信息**、无隐藏牌、无实时操作，胜负取决于**决策质量**。
- 每一步都要权衡：走位 / 换血 / 留技能 / 抢 Buff / 推塔节奏。

### 支柱二：英雄有性格（差异化对抗）
- 五大定位（坦克 / 战士 / 刺客 / 法师 / 射手）+ 专属技能，形成**克制与连招**。
- 阵容搭配、先手顺序、技能 Combo 构成策略空间。

### 支柱三：目标即推塔（清晰的胜利线）
- 不是「将死一子」，而是**摧毁水晶基地**——鼓励**进攻、运营与团队推进**。
- 提供多种取胜路径：正面团战碾压、刺客绕后偷家、法师消耗控场。

## 1.5 与既有品类的差异化

| 维度 | 中国象棋 | 国际象棋 | MOBA 手游 | **王者万象棋** |
| --- | --- | --- | --- | --- |
| 信息 | 完全 | 完全 | 部分（战争迷雾） | **完全** |
| 节奏 | 回合 | 回合 | 实时 | **回合** |
| 棋子差异 | 固定走法 | 固定走法 | 英雄技能丰富 | **英雄 + 技能 + 成长** |
| 成长 | 无 | 升变 | 装备 / 等级 | **能量 / Buff / 装备（规划）** |
| 胜利条件 | 将死 | 将死 | 推掉基地 | **摧毁水晶基地** |
| 随机性 | 无 | 无 | 中 | **可配置（默认无随机，纯策略）** |

**核心差异化定位：** 「像象棋一样纯策略、像 MOBA 一样有英雄和推塔」。

## 1.6 设计哲学与红线

- **易学难精**：5 分钟学会规则，数百小时钻研阵容与连招。
- **默认零随机**：竞技对局以纯策略决胜；随机性仅作为休闲模式的可选调味。
- **对称公平**：镜像布局、同一英雄池，胜负只取决于操作与决策。
- **可读性优先**：任何数值 / 技能都要能在棋盘上「看得懂、算得清」。
- **反滚雪球红线**：领先方不应无脑扩大优势，需保留翻盘窗口（见 05 经济设计）。

## 1.7 愿景

打造**回合制策略对抗的新标杆品类**——
让「策略棋」拥有 MOBA 的英雄魅力与推塔快感，
让「MOBA」拥有棋类的深度、公平与可异步、可复盘的长尾生命力。
