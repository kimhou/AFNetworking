# 02 · 核心玩法与规则

> 本文件是**权威规则书**。原型（`prototype/`）实现的是本规则的**标准简化版**，
> 文中标注 `【原型已实现】` / `【规划】` 以区分。

## 2.1 对局目标

**摧毁对方的水晶基地（Nexus）即获胜。** `【原型已实现】`

- 每方在己方底线中央拥有 1 座**水晶基地**，初始生命 **50**。
- 基地可被普攻 / 技能攻击，生命归零即判负。
- 若达到**回合上限（默认 40 回合）**仍无人摧毁基地，则**基地剩余生命高者获胜**；相等则平局。`【规划】`

## 2.2 棋盘与阵营

- 棋盘为 **9×9 方格**（详见 [04 棋盘与地形](04-棋盘与地形系统.md)）。`【原型已实现】`
- **蓝方**位于棋盘下方，**红方**位于棋盘上方，镜像对称。
- 蓝方先手（后手方在首回合额外 +1 能量作为先手补偿）。`【原型：蓝方先手】`

## 2.3 棋子：英雄

- 每方开局携带 **5 名英雄**，对应五大定位。`【原型已实现】`
- 每个英雄拥有以下属性（详见 [03 英雄系统](03-英雄与技能系统.md)）：

| 属性 | 缩写 | 含义 |
| --- | --- | --- |
| 生命 | HP | 归零则阵亡、移出棋盘 |
| 攻击 | ATK | 普攻基础伤害 |
| 防御 | DEF | 受到伤害的固定减免 |
| 移动力 | MOV | 每回合最大移动格数（曼哈顿距离） |
| 射程 | RNG | 普攻可达的最大距离（切比雪夫距离） |
| 护盾 | SHD | 临时护盾，优先于 HP 承伤（可由技能提供） |

## 2.4 回合结构

对局由**双方交替的回合**构成。每个玩家回合按顺序进行：`【原型已实现】`

```
① 回合开始阶段
   - 能量 +2（上限 10）
   - 结算持续效果（护盾计时、Buff 计时、灼烧等）
② 行动阶段
   - 你可以按任意顺序操作你的每一个英雄
   - 每个英雄本回合最多：移动 1 次 + 行动 1 次（普攻或技能，二选一）
   - 允许「先移动后行动」或「先行动后移动」或「只移动 / 只行动 / 不动」
③ 结束阶段
   - 主动结束回合，交给对手
```

### 关键约束
- **一个英雄一回合内**：移动 ≤ 1 次，攻击 / 技能合计 ≤ 1 次。
- 已行动过的英雄会被标记，回合内不可重复行动（原型以置灰/标记显示）。
- 能量为**全队共享资源**（不是每个英雄独立），鼓励「集中爆发」的策略取舍。

## 2.5 移动规则

- 英雄可移动到 **曼哈顿距离 ≤ MOV** 的空格。`【原型已实现】`
- **不可穿越**其他棋子或基地（原型采用「目标格可达且为空」的判定，`【规划】` 中加入寻路与阻挡）。
- 不可移动到己方 / 敌方基地所在格。
- 草丛地形：进入后**隐身**，敌方普攻无法以其为目标，直到其离开草丛或主动出手。`【原型：草丛提供闪避/标记】`

## 2.6 普攻规则

- 目标：**射程（切比雪夫距离 ≤ RNG）内**的敌方英雄或敌方基地。`【原型已实现】`
- 伤害结算：

```
实际伤害 = max(1, 攻击方 ATK - 目标 DEF)
先扣护盾 SHD，再扣生命 HP
```

- 近战（RNG=1）需贴身；远程（RNG≥2）可隔空攻击。
- **无随机命中 / 暴击**（默认竞技规则）；暴击、闪避等作为休闲模式可选项。`【规划】`

## 2.7 技能规则

- 每个英雄拥有 **1 个主动技能**（专属），消耗**能量**释放。`【原型已实现】`
- 技能拥有：能量消耗、作用射程、效果类型（伤害 / AOE / 位移突进 / 护盾等）。
- 释放技能视为该英雄本回合的「行动」，之后不能再普攻。
- 技能不受普攻射程限制，使用技能自带的射程。
- 详细技能列表与连招见 [03 英雄与技能系统](03-英雄与技能系统.md)。

## 2.8 野区与 Buff

- 棋盘中央为**野区 Buff 格**（暴君 / 主宰位）。`【原型已实现：中央 Buff 格】`
- 英雄**站上并停留**在 Buff 格，可获得增益：
  - **红 Buff（暴君）**：ATK +2，持续到离开或阵亡。
  - **蓝 Buff（主宰）**：每回合额外 +1 能量。`【规划：双 Buff 分离】`
- 野区是兵家必争之地，鼓励双方在中路交锋。

## 2.9 阵亡与复活

- HP 归零：英雄立即移出棋盘。`【原型已实现：移除】`
- **复活机制** `【规划】`：阵亡英雄经过 N 回合在己方基地旁复活（类似 MOBA 死亡等待），使对局更耐久、减少一波崩盘。
- 竞技「秒杀模式」`【规划】`：阵亡不复活，考验极限运营。

## 2.10 胜负判定

| 条件 | 结果 |
| --- | --- |
| 对方基地 HP ≤ 0 | **你获胜** `【原型已实现】` |
| 己方基地 HP ≤ 0 | 你落败 |
| 达到回合上限 | 基地剩余 HP 高者胜，相等平局 `【规划】` |
| 一方全部英雄阵亡且无复活 | 判负（秒杀模式）`【规划】` |

## 2.11 一局示例（推荐开局思路）

1. **前 2–3 回合**：中路英雄向野区推进，争夺中央 Buff。
2. **中期**：法师 / 射手远程消耗，坦克顶在前排，战士寻找突进换血机会。
3. **抓单**：刺客绕侧翼，配合能量集中，一回合内位移 + 技能秒掉对方脆皮（法师 / 射手）。
4. **推进**：清掉对方前排后，集火水晶基地。
5. **收官**：算清能量与行动次数，确保「这一回合能打掉基地最后一段血」，避免被反打。

> 核心乐趣：**能量是共享且有限的**——你必须在「抢 Buff / 保英雄 / 秒对面 / 推基地」之间做取舍，这就是王者万象棋的策略深度所在。
