# 05 · 数值经济与平衡

## 5.1 数值设计目标

1. **可读**：棋盘上的每个数字（HP/ATK/DEF/MOV/RNG/能量）都能被玩家心算。
2. **有取舍**：不存在无短板的英雄；强一项必弱一项。
3. **可调**：以少量「杠杆参数」调平衡，避免牵一发而动全身。
4. **反滚雪球**：领先方难以无限扩大优势，始终保留翻盘窗口。

## 5.2 核心数值框架

### 有效生命值（EHP）
```
EHP ≈ HP / (1 - DEF/参考ATK)   （简化直觉：HP + DEF 提供的等效血量）
近似：一次普攻实际伤害 = max(1, ATK - DEF)
```

以原型五人组，对「ATK=6 的战士」而言的**挨打次数**：

| 英雄 | HP | DEF | 被 ATK6 打死所需次数 |
| --- | --- | --- | --- |
| 盾山 | 30 | 3 | ⌈30 / (6−3)⌉ = **10** |
| 铠 | 24 | 2 | ⌈24 / 4⌉ = **6** |
| 后羿 | 17 | 1 | ⌈17 / 5⌉ = **4** |
| 阿轲 | 16 | 1 | ⌈16 / 5⌉ = **4** |
| 妲己 | 15 | 1 | ⌈15 / 5⌉ = **3** |

> 直观结论：坦克抗打是脆皮的 **2.5–3 倍**，符合定位预期。

### 能量经济
- 每回合 +2，上限 10，全队共享。
- 技能成本 4–5：意味着**每回合大约能放 1 个技能**，攒 2–3 回合可打一套 Combo。
- 这是**节奏调速器**：能量越贵，节奏越慢、越考验运营。

## 5.3 平衡杠杆优先级

调整平衡时，**从上到下**优先使用，越靠上越可读、越易回滚：

1. **能量成本**（首选）：改技能贵/便宜，不动数值手感。
2. **射程 / 移动力**：改「够不够得着」，战术影响大但直观。
3. **技能威力 / 范围**：改爆发上限。
4. **基础 ATK/DEF/HP**（末选）：牵动全局，最后才动。

## 5.4 反滚雪球机制

| 机制 | 作用 |
| --- | --- |
| 阵亡复活（规划） | 一波团灭不至于直接崩盘，给翻盘时间 |
| 落后补偿（规划） | 基地血量落后方，能量回复 +1 或击杀赏金更高 |
| 能量上限 | 防止无限攒大招一波带走，压制爆发上限 |
| 基地高血量（50） | 推塔需要多回合投入，给防守方反应窗口 |

## 5.5 经济成长系统（规划）

```
金币来源：击杀英雄(+X) / 占领野区(+Y/回合) / 拆塔(+Z)
金币用途：购买装备（ATK/DEF/HP/特殊被动）
成长曲线：前期靠基础属性，中期装备成型，后期技能升级树见胜负
```

- 设计红线：**经济领先 → 属性领先，但不应线性碾压**；装备提供「质变节点」而非无限叠加。

## 5.6 平衡验证方法论

1. **数学建模**：用 EHP / DPS / 每能量伤害（Damage per Energy）横向对比英雄。
2. **AI 自对弈（Self-play）**：让 AI 大量对局，统计**英雄胜率 / 登场率 / Ban 率**。
   - 目标：主流英雄胜率收敛于 **45%–55%**。
3. **对局数据埋点**：平均局长、平均回合数、首杀回合、翻盘率。
4. **分层测试**：新手 / 高手分池，避免「高手强、新手弱」的一致性偏差。
5. **灰度调参**：每次只动 1–2 个杠杆参数，A/B 对照观察胜率漂移。

## 5.7 关键平衡指标（KPI）

| 指标 | 健康区间 |
| --- | --- |
| 单英雄胜率 | 45% – 55% |
| 平均局长 | 5 – 15 分钟 |
| 平均回合数 | 12 – 30 |
| 翻盘率（落后方逆转） | 15% – 30% |
| 先手方胜率 | 50% – 54%（有补偿） |

> 数值不是一次做对，而是**持续观测 + 小步快调**的长期工程。原型已把数值集中在 `heroes.js` / `game.js` 顶部常量，便于快速试验。
