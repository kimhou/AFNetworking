01 常小鹅（常小娥）棋手机制

常小鹅是「等级滚雪球 / 助力成长」型棋手，不占阵容位。她不指定唯一主核，而是靠把等级源源不断地灌进你选定的核心，用等级总和触发「送福」滚雪球。

🐇 技能 · 小菟助力

使用技能，随机助力 1 名英雄，使其等级 +2。本场比赛中，小菟每助力过 1 次，等级提升效果 +1（越用越强，故要早用、常用，别囤着浪费）。

✨ 秘技 · 兔飞猛进

己方英雄等级总和达到 50 / 150 / 375（官网数值；部分攻略记为 50/175/400，以游戏内为准），各获得 1 张秘技牌「小菟送福」：对场上随机 4 名英雄各触发 1 次小菟助力（+2 级）。

🌙 专属 · 月之特调

核心每提升 5 级，循环获得额外属性：攻速 15% / 物法吸血 2% / 物法双防 2；每通过助力提供 65 级，再获 1 张小菟送福。等级越高，属性与送福越滚越多。

🧭 核心思路

  • 等级总和是核心指标：围绕 50/150/375 三个送福节点规划。
  • 集中不分散：把助力尽量堆到少数核心；别铺满人口，多余棋子会稀释等级节奏。
  • 助力随机 → 阵容搭配要灵活，让"随便助力谁都不亏"。

02 通用开局铁律（前 3 回合）

无论走哪条起手，常小鹅的前期节奏高度一致：攒能量、早助力、少刷新、苏烈顶血。

回合目标关键操作
R1攒能量只买 1 张过渡英雄（苏烈最优，顶前排稳血），其余能量攒到 R2。
R2开启助力棋手升 2 级，开始小菟助力；此后每回合都用一次助力（次数越多加成越高）。
R3零刷新找核心棋手升 3 级；7 回合前尽量零主动刷新，只用免费刷新搜核心；第 3 回合后首次拍卖，抢起手核心 / 升星·升级增益牌。
🔑 三个拍卖节点：第 3 / 7 / 11 回合后。首拍抢起手核心；二拍（R7 后）几乎都优先 太乙真人（保己方 C）；三拍（R11 后）按血量/等级补强或拿保命牌。二拍后通常升 6 人口开始大搜。

03 起手 A：狂铁 → 远方 / 日落海「整备等级流」

最稳的滚雪球路线：狂铁自带 整备，配合常小鹅的助力/送福，等级双重叠加，全员越滚越高直至 999。

衍生分支

狂铁 起手
+ 苏烈 = 远方羁绊
远方整备流：狂铁 + 苏烈 + 元芳 + 安琪拉 + 程咬金 / 朵莉亚
日落海整备流：狂铁 → 亚连 → 安琪拉（法核）→ 朵莉亚 → 雅典娜 / 海诺 / 露娜（闭环，全员自动升级）

关键英雄与词条

狂铁苏烈元芳 安琪拉亚连朵莉亚 雅典娜海诺露娜太乙真人
  • 狂铁 整备「整备共鸣」：每回合开局给已上阵的日落海英雄临时 +级；技能双击挥砍两次普攻后对周围造成 50 固定伤害。启动核心，优先觉醒。
  • 苏烈 牺牲：死后自身永久 +2 级，前排过渡兼吃等级。
  • 亚连「赤影整备」：场上仅 1 名日落海英雄装备时，全体友军 +2 临时级；常驻被动即可，觉醒优先级低于狂铁/安琪拉。
  • 安琪拉：法强核心，所有法术强度装备优先给她。
  • 朵莉亚 登场：机制类似小乔，激活友军整备并叠额外等级。
  • 露娜 / 雅典娜 / 海诺：闭环三件套，集齐后统一觉醒养级。

逐回合运营

回合做什么
1–3搜 狂铁 / 苏烈，尽快合成觉醒狂铁；每回合助力优先喂狂铁或后续核心；苏烈顶前排稳血。
首拍(R3后)优先 升星 / 升级增益牌，或抢核心日落海牌。
4–7狂铁 3 星，补 安琪拉 / 元芳 搭骨架；观察对手，决定是"有 1 张体系牌就升本"还是"刷新觉醒"。
二拍(R7后)优先 太乙真人；随后升 6 人口，凑齐日落海 6 张触发人口/秘技，开始大搜。
8–14补齐 亚连 / 朵莉亚 / 雅典娜 / 海诺 / 露娜，挂机升级；血健康拿等级/经济天赋，危险拿战力天赋直接打。
决赛按需上反制牌：太乙(复活自家 C)、海月(牵制敌 C)、钟馗(压敌主 C 等级)。对手有刺客给 C 名刀，有强控给净化/炽热。
⚠️ 整备只对回合开始前已上阵且未被替换的单位生效——不要频繁替换核心棋子，否则吃不到加成、成型变慢。

04 起手 B：苏烈 → 嫦娥四人队（马超控制核心）

苏烈是万金油前排起手（几乎所有阵容都能用它过渡）。常小鹅招牌是嫦娥四人队：以马超为绝对输出轴心，四核到位即成型，不必凑满 5 人。

衍生分支

苏烈 起手
前排过渡·吃等级
嫦娥四人队：马超(主C) + 瑶 + 苏烈 + 吕布（+太乙 / 钟馗 / 海月）
马超控制流(扩展)：刘禅 + 大乔 + 蔡文姬 + 马超 + 诸葛亮（控制链锁血）

机制闭环：控制 → 增益 → 续航

马超瑶苏烈 吕布太乙真人钟馗海月
  • 瑶：达到 40 级 后普攻附带硬控，是控制链的开关。
  • 马超（主 C）控制联动：己方每触发一次控制 → +15 法力值 + 5% 暴击率，持续叠加，输出滚起来。
  • 苏烈 牺牲：前期坦度过渡 + 吃等级。
  • 吕布：进一步强化马超的吸血续航。
  • 常小鹅：拉等级，且每 5 级随机赋予吸血 / 攻速，直接放大马超续航与输出。
🧰 出装：马超 → 无尽 + 自然法杖 + 魔律之刃；瑶 → 近卫荣耀 + 破茧之衣；肉装给苏烈，多余给吕布。

逐回合运营

回合做什么
1–3只单挂苏烈顶血；每回合用一次助力（别浪费，影响后期金卡技能触发）。
首拍(R3后)留意 马超、瑶 的来牌，优先拿。
R4可上 弈星 帮助升级；天赋优先经济类，血量不健康则拿回血天赋。
5–7继续攒能量；7 回合前只用免费刷新找马超和瑶，别干扰拍卖预算。
二拍(R7后)优先 太乙真人；随后升 6 人口 大搜，合成马超 / 瑶三星，或拿升级效果牌喂常小鹅属性成长。
8–14四核（马超/瑶/苏烈/吕布）稳定在场；太乙、钟馗、海月 按对局保留补强；别多凑人口拖慢等级。
⚠️ 命脉是控制链不断档：瑶要尽快到 40 级，硬控触发才能喂马超法力与暴击；控制被免疫/净化时输出会明显掉档。

05 起手 C：干将 → 法核 / 无限技能流（前期打工，后期转核）

干将莫邪是成长型远程法师：击败敌人永久 +级，靠觉醒后不断击杀滚雪球。核心打法是前期用干将叠等级压制，后期把等级「传承 / 遗志」转给更强法核（诸葛亮 / 海月）。

干将技能：雌雄双剑

  • 释放 1 对飞剑，造成 100 + 50% 法强 伤害；10 级→150+100%；40 级→每第 2 次施法追加 1 对飞剑；100 级→150+200% 法强。
  • 上场即解锁专属装备 双剑·雄；击杀叠级 击败敌方永久 +级 → 越滚越强。

衍生分支

干将 起手
前期打工·叠等级
常小鹅无限技能流：常小鹅 + 干将 + 诸葛亮——干将过渡叠级，传承给诸葛亮，达成"一秒一个元气弹"高频伤害
阿离遗志干将：前期干将/孙膑/曜/牛魔/猪八戒 → 后期换海月/扁鹊/太乙；圣杯/贤者天书天赋叠级转核

关键英雄与词条

干将诸葛亮苏烈 孙膑海月扁鹊太乙真人钟馗
  • 干将 击杀叠级：前期抢牌、一级觉醒，靠击杀堆等级、开局压制。
  • 诸葛亮（后期法核）：承接干将转移来的等级，高频元气弹爆发，补上"纯干将后期群伤不足"的短板。
  • 传承 / 遗志 传承：把干将的等级转移给高阶法核，转移后干将可卖出让位。
  • 常小鹅：助力堆干将快速觉醒滚雪球；后期送福同样能砸到诸葛亮法核上。

逐回合运营

回合做什么
1–3抢 干将，一级觉醒；助力优先喂干将；苏烈顶前排。靠击杀开始叠级、争前期连胜。
4–7继续靠击杀叠级；十张手牌存三级囤组件；有体系牌就升本。
二拍(R7后)找 五阶法核 / 诸葛亮 组件，太乙真人保命。
8–14用传承 / 遗志把等级转给诸葛亮，干将转移后卖出让位；补 太乙 / 海月 / 钟馗 反制。
⚠️ 纯干将后期群体输出不足、上限偏低——必须提前安排等级转移到诸葛亮等法核，转核失败容易在终盘崩盘。

每套一句话总结

狂铁·整备等级流

优点

  • 滚雪球稳、平滑
  • 后期 999 等级/武器碾压
  • 容错高、无脑上分

缺点

  • 前期战力弱、成型慢
  • 怕强控与快攻
  • 依赖驻场、怕 ban 日落海

嫦娥四人队

优点

  • 中前期锁血强、抓单
  • 节奏可控、容错高
  • 四核即成型、省人口

缺点

  • 后期瞬爆上限略低
  • 怕抗控/净化
  • 控制断档即乏力

干将·法核流

优点

  • 开局压制、连胜起势
  • 转诸葛亮上限高
  • 门槛低、圣杯加成大

缺点

  • 纯干将终盘乏力
  • 吃觉醒与转核操作
  • 怕钟馗/肉阵/控制

克制关系（速记）

🔁 三角克制：整备等级流 压制 慢速单核，但怕 控制流； 控制流 锁死 施法/爆发脆皮，但怕 抗控 & 高成长等级流后期反打； 干将法核 前期压制 慢热阵容，但怕 钟馗压等级 & 强前排。

🛡️ 万能克制手：钟馗

压低敌方最强主 C 等级，是所有"养大哥/等级流单核"阵容的通用克星，逆风翻盘位。三套阵容决赛都可按需补入。

🗡️ 关键反制装备

对手强控 → 净化/炽热支配者/纯净苍穹；对手刺客 → 名刀·司命；遇闪现阵容 → 前后排交换站位；遇钟馗/太乙/图腾 → C 位别放最角落，往前放。
