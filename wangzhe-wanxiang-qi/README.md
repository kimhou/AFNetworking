# 王者万象棋 · 玩法与上分方案（可视化 HTML）

一份针对腾讯《王者荣耀》英雄策略自走棋 **王者万象棋**（S1 公测）的**可视化攻略方案**，单文件 HTML，双击 [`index.html`](index.html) 即可在浏览器打开，无需任何依赖或构建。

## 内容

- **① 玩法总览**：6 人自走棋、60 血淘汰制、「一刷 / 二养 / 三炸场」核心。
- **② 核心机制**：固定经济、升本节奏、拍卖（3/7/11 回合）、棋手系统、10/40/100/999 级质变。
- **③ 关键词条**：登场 / 整备 / 交锋 / 牺牲 / 闪现 / 古币 / 图腾 / 效果牌。
- **④ 关键英雄与棋手**：主 C 候选、功能核心、棋手推荐（按阵营配色）。
- **⑤ 当前最强 T0 阵容**：复活木兰、三分倒转、日落海整备、大河图腾、河洛古币、逐鹿嬴政。
- **⑥ 详细操作手法**：分阶段运营时间线、四条铁律、招牌连招、常见误区。
- **⑦ 来源与免责声明**。

## 专题文档

- [`changxiaoe-openings.html`](changxiaoe-openings.html)：**常小鹅（常小娥）起手分支与阵容运营详解** —— 以常小鹅为棋手，狂铁 / 苏烈 / 干将 三种起手如何衍生阵容、逐回合怎么运营、英雄搭配与词条机制，以及各阵容的**特点 / 优缺点 / 克制关系**。

## 打开方式

直接双击 `index.html`；或本地起服务：

```bash
cd wangzhe-wanxiang-qi
python3 -m http.server 8000   # 浏览器打开 http://localhost:8000
```
