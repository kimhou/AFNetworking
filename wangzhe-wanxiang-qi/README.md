# 王者万象棋（King's Myriad Chess）方案研究项目

> 一款融合 **MOBA（王者荣耀式英雄对抗）** 与 **中国象棋 / 回合策略棋** 的原创策略棋类游戏方案。
> 本仓库目录既包含**完整的设计方案文档**，也包含一个**可在浏览器中直接游玩的交互原型**，用于验证核心玩法的可行性与乐趣。

---

## 一句话概括

> 双方各率领 5 名「英雄棋子」，在一张带有兵线、野区与地形的棋盘上回合制博弈，
> 通过走位、普攻、释放技能、争夺 Buff，最终**摧毁对方水晶基地**取胜。
> 它把 MOBA 的「英雄 / 技能 / 推塔」体验，浓缩进象棋般清晰、可深度钻研的回合制规则里。

## 为什么做这个方案（立项动机）

1. **传统棋类**（象棋、国际象棋）规则优雅、易学难精，但缺乏成长、技能、随机性带来的现代娱乐感。
2. **MOBA 手游**（王者荣耀等）体验极佳，但强依赖操作、网络与实时对局，**碎片化、可异步、可思考**的场景缺位。
3. 「王者万象棋」用**回合制棋盘**承载 **MOBA 的策略内核**：
   - 保留象棋的「完全信息 + 深度策略 + 一步一世界」；
   - 注入 MOBA 的「英雄差异化 / 技能连招 / 资源运营 / 推塔目标」；
   - 天然适合**单机 AI、异步对战、赛事解说、教学复盘**。

## 快速开始：运行可玩原型

原型是**零依赖**的纯前端实现，任意静态服务器即可运行：

```bash
cd wangzhe-wanxiang-qi/prototype
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

你将得到一个**蓝方（你） vs 红方（AI）** 的完整对局：
选中英雄 → 高亮可移动格 / 可攻击目标 → 移动、普攻或释放技能 → 击破对方水晶基地取胜。

> 详细的玩法说明见原型内置面板与 [`docs/02-核心玩法与规则.md`](docs/02-核心玩法与规则.md)。

## 原型已实现的核心闭环

- ✅ 9×9 棋盘、双方水晶基地、中央野区 Buff 格、草丛地形
- ✅ 五定位英雄（坦克 / 战士 / 刺客 / 法师 / 射手），差异化属性
- ✅ 回合制：能量获取、移动力、普攻射程、技能释放
- ✅ 每个英雄独立主动技能（护盾 / 突进 / 位移刺杀 / 十字 AOE / 远程爆发）
- ✅ 伤害结算、护盾、阵亡移除、野区 Buff 争夺
- ✅ 胜负判定（摧毁基地）与对局日志
- ✅ 基础对手 AI，可单人游玩演示
